## R10 causal campaign

`bash tools/ps5/test-r10.sh "$MODEL_MOE" results/r10-layer0` (new output directory). The same two R9 prompts are each run in six fresh processes, with one fixed-token decode per prompt. No MTP, no heterogeneous scheduling, no production promotion. Repeat with `PS5_R9_LAYER=1` or `PS5_R9_RANK=3` only after all controls pass. `PS5_R10_TIMEOUT` default 5400 seconds per process; preserve failed logs.

Arms:
1. gpu: unchanged all-GPU control.
2. shadow: diagnostic readbacks and record all ordered router IDs, mixture weights, tokens, raw top-k boundary gaps and tracked pre-router hidden.
3. sham: write back the exact original GPU expert row through the same intervention path. All logits and layer outputs must remain bitwise identical.
4. replay-shadow: record-freeze replay of reference IDs AND weights on every prefill chunk/layer; natural routes are still calculated and logged. All logits and layer outputs must remain bitwise identical.
5. contract: replace one row with R8, leave routes natural.
6. replay-contract: same replacement with frozen IDs AND weights. The selected intervention input, pre-intervention outputs and target combine must match the relevant controls bitwise.

The recorded routes are checked against the prompt tokens, chunk length, layer list, bounds, duplicate IDs and finiteness. Replay uses readback verification. `compare-r10.py` rejects missing traces, changed controls, corrupt tapes and unequal interventions. `summary.json` has residuals at the normalized hidden before router and at the combine boundary, plus natural ordered routing changes and raw score gaps. Raw gaps are not rounded shader probability gaps. The first divergence need not be at MoE: the trace does not split attention/GDN/norm internally. Both IDs and weights are frozen together, so this does not isolate their individual contributions. Replay applies to **prefill only**. Subsequent fixed-token decode routes naturally; interpret the two logit vectors separately. These are counterfactual accuracy experiments, never performance benchmarks. No promotion of R4 even if errors disappear.

Interpretation: if sham fails, inspect write/sync and aliasing. If replay-shadow fails, inspect route upload, cache/staging and synchronization before interpreting any comparison. If both pass and replay-contract substantially reduces the prefill residual, the joint routing/mixture path is an amplifier under the tested prompts. If error persists, investigate attention/GDN/norm, quantization and state propagation before blaming router. Later distinguish routing IDs vs weights with independent controls if indicated. Do not alter production routing or force identical expert selections as a permanent solution.
