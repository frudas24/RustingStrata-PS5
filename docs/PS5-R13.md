## Motivation and scope

AE00 reported 0.455286 ms SSBO vs 0.3123425 ms LDS for a synthetic 4 KiB lookup workload. IQ2_XS's existing 512-entry uint64 grid is 4 KiB. The integer GEMM previously omitted shared tables to stay under other GPUs' LDS constraints; reuse the existing IQ3 grid and IQ4 packed two-nibble lookup in PS5-only variants. The AE00 result is not a prediction of whole-model performance.

| Mode | Routed kernel | Change |
|---|---|---|
| `iq2` | R11 IQ32 FP16 | Cache original 512 x u64 IQ2_XS grid once per group, uniform barrier |
| `int` | integer tile 128, 32 or 64 | Enable existing shared IQ3_XXS grid and IQ4_XS packed two-nibble LUT |
| `all` | both | Combine after individual gates |

`STRATA_PS5_R13_LUT=off|iq2|int|all` (unset/other values off). Requires PS5, built ps5-r2 shaders, wave32, non-cooperative matrices, 64 KiB reported LDS. IQ2 requires `STRATA_PS5_R11_IQ32=1`. Integer geometry chosen independently via `STRATA_PS5_R12_IQ_INT_TILE=0|32|64`. Unsupported device gates preserve the corresponding existing kernel. Actual specialized SPIR-V Workgroup bytes are checked in preflight and pipeline creation; failure is explicit. No extra per-dispatch SPIR-V sizing. No new descriptor layout or weight copies. No change to Q8-32, FP16 rounding, FMA ordering, routing, KV, or the tile-list ABI. IQ4 uses exactly the existing packed byte values (not interpolation). No changes to decode GEMV/down; the first experiment targets the measured prefill bottleneck. Texture binding and alternate register packing are deferred until LDS ROI is known. Extra LDS can lower occupancy; no assumed gain.

## Memory and activation preparation

The current allocator already prefers HOST_CACHED for staging (HOST 0xe then 6) and fresh mapped immutable uploads (15 then 7). Mailbox memory intentionally has different coherence requirements, so forcing HOST_CACHED is unsafe. DEVICE fallback and budgets are unchanged. The buffer-size alignment now uses checked arithmetic. `STRATA_PS5_R13_MEM_TRACE=1` logs successful bound allocation types, heaps, flags and actual allocation size; logs CPU memcpy time by role (immutable upload, staging write/read), excluding GPU/fence time. Allocation totals are cumulative, not current residence. Imported external GGUF memory is not covered; generic device allocations do not identify logical tensor names. No change to placement policy.

The current routed gate/up already uses SAME_X for compatible Q8 activation reuse; explicit prequant_gemm_x also exists. IQ2_XS uses FP16 in this model; do not assume Q8 reuse for it. `STRATA_PS5_R13_QUANT_TRACE=1` logs cache hits/misses and batched FP16 fallback; no change to cache validity/lifetime rules. No new fusion/reuse optimization before measured evidence. Existing STRATA_VK_PROF, STRATA_VK_STATS (if supported) and STRATA_PS5_R11_PROFILE supply dispatch timing, driver stats and GEMM geometry. Timed A/B must not use diagnostic flags. SQTT/SPM, textures, SDMA/ACE, VCN/DMA-BUF, sparse and Zstd remain separate investigations, no integration here.
