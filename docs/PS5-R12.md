## R12 mechanism

STRATA_PS5_R12_IQ_INT_TILE=32 or 64 (default off). Applies only to routed
IQ3_XXS/IQ4_XS integer GEMM on PS5, Wave32, noncooperative, ps5-r2 build.
Original 128-position list stays immutable. Grid z indexes position
subtiles, not K slices, with a uniform early return before any barrier.
Every output retains all K steps and original scale_add and epilogue.
32/64/128 declared LDS: 20.5/27/40 KiB for both formats. Extra empty z
groups and weight rereads can regress occupancy or performance; no win
is asserted. Dense, cooperative, other formats and decode unchanged.
R11 IQ32 remains the explicit baseline in both benchmark and quality arms
for iqint32/iqint64; require the IQ32 marker in both and new marker only
in the candidate. No other candidate is activated by ambient env.

STRATA_PS5_R12_BOUNDARY_TRACE=1 is research only, requires R10. Captures
raw FP32 bits for all tokens in the intervention chunk at layer input,
mixer norm, mixer residual, FFN norm and layer output for nine layers
starting at the intervention. Bound to <=262144 floats per vector;
rejects invalid ranges, non-finite values and inconsistent coordinates.
PS5_R12_BOUNDARY_TRACE=1 tools/ps5/test-r10.sh enables it only in the
instrumented arms; compare-r12-boundaries revalidates R10 controls, full
coverage, unchanged preintervention stages, unchanged unselected tokens,
and identity of the initial substituted chunk across replay/natural.
No causal fix is claimed. Does not capture all internal GDN/KV operations.

## Physical acceptance (in this order)

1. Build R12 on PS5. Run `bash tools/ps5/test-r11u1-audit.sh --offline`,
   `--cpu`, `--gpu`; `bash tools/ps5/test-r11u1.sh --compile` and
   `--batch "$MODEL_MOE" "$PWD/results/r12-batch.log"`.
   Do not promote any changes if these fail. Verify 648 R11 cases again
   (`test-r11-iq.sh "$MODEL_MOE" results/r12-r11-parity`) and reproduce
   IQ32 benchmark/quality on merged HEAD.
2. `python3 tools/ps5/check-r12.py`; `bash tools/ps5/test-r12-iq.sh results/r12-iq-parity`
   expects 1296 cases per arm, 0/32/64 in separate processes with complete
   buffers, two experts, gaps, indexing, row/position edges and act=0/1/2.
3. For each of `iqint32` and `iqint64` run
   `python3 tools/ps5/bench-r11.py --model "$MODEL_MOE" --candidate "$CANDIDATE" --out "results/r12-$CANDIDATE-8k" --ctx 8192 --pp 128,512,2048,4096 --tg 32 --reps 3 --min-ram-mb 1024`.
   Separate profile-only runs; compare against IQ32, not old baseline.
   No promotion without the 3% aggregate, no phase below -5%, signature
   and dispatch gates. Apply quality-r11.py with the same candidate and
   new independent corpus, then near-limit contexts 8K/32K/64K with
   memory guard, real tokens and raw logs. Check cache residency and swap.
4. `PS5_R12_BOUNDARY_TRACE=1 bash tools/ps5/test-r10.sh "$MODEL_MOE" results/r12-causal`.
   Repeat layer 1 and rank 3 if necessary. These times are not benchmarks.
5. Keep IQ32 as explicit recommended tested configuration on original
   R11, then on merged R12 only after regressions pass. Example:
   `STRATA_PS5_R11_IQ32=1 STRATA_VK_NO_COOP=1 STRATA_PS5_R12_IQ_INT_TILE=0 bash tools/ps5/run.sh chat --model "$MODEL_MOE" --ctx 8192 --chunk 512 --threads 6 --kv q8 --mtp 0`.
