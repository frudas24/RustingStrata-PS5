## Adoption matrix

| Feature | Decision | Details |
|---|---|---|
| Independent K/V formats | Adopt + harmonize | Backend, Vulkan pipeline specialization IDs 15/16, GPU cache sizes and R5 pair-load paths. F16 is handled separately per side. R5 permits legacy F16/Q8/Q4/Q2 pairs, not TurboQuant. |
| Host-attention / host KV | Keep upstream, gate PS5 | CUDA implementation retained; Vulkan does not override the default `alloc_host`/`attn_host`. On PS5 reject `STRATA_KV_HOST` rather than waste memory on redundant staging. Fix general staging sizing independently for K and V, using absolute layer index and checking capacity instead of truncation. |
| TurboQuant | Keep upstream CUDA / quarantine PS5 Vulkan | Upstream explicitly reports wrong text on Vulkan and gates it. Additionally tiled shader calls `rotate_q(qv, lane)` before initialization in supplied source. PS5 profile rejects TurboQuant even if the upstream test override is set. Upstream SPIR-V is kept byte-for-byte; do not claim this fixes TurboQuant. |
| Batched GEMM split-K and 64-position tiles | Adopt + harmonize | Upstream new SPIR-V and host dispatch intact, plus preflight for `gemmi_s2` variants. Cooperative path requires actual driver capabilities; R2's non-cooperative 32-position path stays separate and uses one K segment. The upstream unconditional guard for scale loading subsumes our row guard; keep the R2 column guard for SM1. |
| Dynamic KV growth / batching | Adopt | Dense multi-slot growth only under upstream conditions; does not automatically reduce single-session 64K allocation, nor MoE capacity. Validate graph invalidation and resize memory peaks. |
| Expert prefill protection | Adopt upstream policy | Both fork and upstream implement prompt blending, next-layer cold read-ahead and page-cache hints. One implementation only. Default OFF (fork default ON); upstream comment reports 83% -> 76% reply hit rate with protection on for one Qwen3.6-35B-A3B test. `1` and `strict` remain available. R6 autotune pins `0`. Read-ahead and cold release remain upstream behavior even when protection off. R3 `weights::cold` import guard remains. |
| CPU kernels / AVX2 | Merge | Preserve fused Q8_K sums and cached activation quantization, take upstream CPU changes. SIMD C checks do not prove full Rust numerical parity. |
| New architectures and model fixes | Adopt | Raon, Inkling 2, Gemma, DeepSeek, GLM, tokenizer/grammar, vision and serving changes included as upstream; not evidence of PS5 model support. |
| Vulkan SPIR-V | Adopt matched binaries | Retain all upstream precompiled modules; local R2/R5 variants generated by `build.rs` from harmonized sources, validated with `spirv-val` at build time. |
| R6 benchmark / autotune | Harmonize | Keep old symmetric legacy profile contract, explicitly refuse mixed modes with R6 trace, add `kv_k`/`kv_v` to generic bench JSON. Ordinary bench can evaluate mixed KV. Profiles must be recalibrated; binary hash invalidates old profiles. |
| R1–R6 experimental controls | Retain | GTT, direct upload, immutable GGUF import, R4 policy, R2/R5 shaders, autotuner, PGO tools remain. No forced enable of experimental kernels. |

## Historical evidence supplied in fork

The archived fork README reports Qwen3.6-35B-A3B UD-Q2_K_XL, Linux 7.3.3, `amdgpu.gttsize=12888`, Vulkan, ctx8192/chunk512/KV q8/6 threads/MTP off/fixed experts, three samples per cell on one console in one serial session:

| | pp512 prefill/decode | pp4096 prefill/decode |
|---|---|---|
| R1 profile ON | 294.5 / 86.8 tok/s | 347.0 / 83.5 tok/s |
| Same binary, profile OFF | 144.9 / 33.2 | 300.1 / 41.5 |

Reported expert residency 9703/10240 vs 5344/10240 and hit rates 94.2% vs 51.4%. This is important evidence in favor of R1, but raw benchmark records were not included in the supplied archives. Neither R2–R6 nor this merge inherits those numbers as measurements. No boot options are changed by this package.

## Validation in preparation environment

See `validation-r6u1/`. PASS: independent R1 C SIMD (1,000,000 vectors, 2,000,000 sums), R2–R5 Python geometry/model checks, 3 upstream KLD Python tests, Python AST and shell syntax, mixed KV budget smoke, and the first nine R6 controller tests including simulated end-to-end calibration. The tenth R6 test (child timeout/failure) was interrupted by the enclosing environment timeout: NOT_RUN_TO_COMPLETION, not PASS. Full Rust build, new GLSL/SPIR-V build, GPU parity, runtime Vulkan and physical benchmark are BLOCKED here (cargo/rustc/glslc/spirv-val and physical PS5 not available). Static merge and ZIP integrity are not a build certification.

## Target rollout

1. Finish the ongoing R7 research on the unchanged baseline; record binary and model hashes.
2. Extract R6U1 in a separate directory, with separate `CARGO_TARGET_DIR` and output directories. `bash tools/ps5/build.sh`, then `bash tools/ps5/test-merge.sh` (compile all test targets, CPU-only checks). If failures occur, preserve logs; do not claim successful compilation merely from an independent C/Python check.
3. `bash tools/ps5/test.sh --gpu`, `bash tools/ps5/test-r2.sh`, `bash tools/ps5/test-r5.sh`. R5 now tests 8 K/V pairs by default; `PS5_R5_ALL_PAIRS=1` covers 16 pairs. Compare against 1.4.0 tiled baseline. R3 strict test needs effective host import and may legitimately be unsupported. R4 requires a compatible MoE and effective hybrid execution.
4. Run R6 vs R6U1 (same profile-on flags, model, context, chunk, KV, threads, MTP, fixed experts, temperatures and prompt). Keep R6U1 R2–R5 variants off for the initial comparison. A/B/B/A with at least three repeats per phase, separate output directories. Do not run parallel benchmarks on the same PS5. Then compare new features individually.
5. Explicitly compare `STRATA_PREFILL_PROTECT=0`, `1`, `strict` on a separate adaptive-cache run; fixed experts can mask cache policy differences. Check expert hit rates, SSD reads, TTFT and decode rate, not just prefill. Calibrate new profiles only after physical parity.
6. Mixed KV experiment: `bash tools/ps5/run.sh chat --model "$MODEL" --ctx 8192 --k q8 --v q4` (keep symmetric `--kv q8` reference); compare quality before 64K. `tools/ps5/kv-budget.py` now accepts `--k` and `--v` for independent payload estimates. 32 layers/8 KV heads/128 dims/64K: Q8/Q8 4.25 GiB; Q8/Q4 3.25 GiB, saving 1 GiB in payload only.

## Open risks for R7

- Existing `attn_merge` fully-empty splits can encounter `-inf - -inf` or zero denominator. Need reachable-state proof and rebuilt shader before fixing; this merge does not change the shipped SPIR-V.
- Upstream TurboQuant tiled shader reads uninitialized query vector before rotation; other Turbo paths and LDS limits need independent audit. No unverified Turbo shader replacement shipped.
- Existing MoE shared-flag race hypothesis remains unresolved. Do not mark it fixed from merge alone.
- Upstream split-K allocates scratch with `expect`; low-memory behavior needs validation (normally gated by cooperative INT8 capabilities). Dynamic KV resize temporarily holds old and new buffers. Measure capacity and graph invalidation before promotion.
- The controller R6 may favor a configuration only within its measured workloads. Do not promote mixed formats or unmeasured architectures into its symmetric profile schema. The archived fork mentions real tags and branches, but this package does not reconstruct or assert their Git history.
